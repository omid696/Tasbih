# Tasbeeh Android / WebView

برنامه تسبیح سبک، آفلاین و مبتنی بر HTML داخل Android WebView.

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. صبر کنید Gradle Sync کامل شود.
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.

Minimum SDK: 23 (Android 6.0)
Target SDK: 35

فایل اصلی رابط کاربری در `app/src/main/assets/index.html` قرار دارد و می‌توان آن را مستقل از Android نیز اجرا کرد.
